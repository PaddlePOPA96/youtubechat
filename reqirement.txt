# PRD — StreamChat Desktop

## 1. Informasi Proyek

- **Nama aplikasi:** StreamChat Desktop
- **Platform:** Windows Desktop
- **Framework:** Electron
- **Frontend:** React + TypeScript
- **Build Tool:** Vite
- **YouTube Library:** `youtubei.js`
- **TikTok Library:** `tiktok-live-connector`
- **OBS Integration:** Browser Source melalui server lokal HTTP dan WebSocket
- **Styling:** CSS
- **Animation:** CSS Keyframes
- **Packaging:** Electron Builder

## 2. Tujuan Aplikasi

Membuat aplikasi desktop berbasis Electron yang dapat membaca live chat YouTube dan TikTok secara bersamaan, menggabungkan chat dalam satu dashboard, serta menampilkan chat dan animasi gift TikTok pada OBS Studio.

Aplikasi harus ringan, responsif, mudah digunakan, dan dapat berjalan selama streaming berlangsung.

### Tujuan utama

1. Membaca live chat YouTube secara real-time.
2. Membaca live chat TikTok secara real-time.
3. Menggabungkan chat kedua platform dalam satu dashboard.
4. Membedakan chat berdasarkan platform.
5. Menampilkan chat melalui OBS Browser Source.
6. Membaca event gift TikTok.
7. Menampilkan animasi gift TikTok secara otomatis di OBS.
8. Menyediakan pengaturan tampilan overlay melalui dashboard.
9. Menangani koneksi terputus tanpa menghentikan platform lainnya.

## 4. Integrasi YouTube Live Chat

Gunakan library `youtubei.js` untuk membaca live chat YouTube.

### Fitur

- Input URL atau ID live stream YouTube.
- Memvalidasi ketersediaan live chat.
- Membaca pesan secara real-time.
- Mengambil username pengirim.
- Mengambil display name jika tersedia.
- Mengambil avatar jika tersedia.
- Mengambil isi pesan.
- Mengambil informasi badge jika tersedia.
- Mengambil timestamp jika tersedia.
- Mengirim data ke sistem Unified Chat.
- Mengirim data ke overlay OBS.
- Menangani error dan reconnect.
- Menampilkan status koneksi YouTube.

### Format data internal

```json
{
  "id": "youtube-message-id",
  "platform": "youtube",
  "username": "PlayerOne",
  "displayName": "Player One",
  "avatar": "https://example.com/avatar.jpg",
  "message": "Halo semuanya!",
  "badges": [],
  "timestamp": 1793000000000,
  "type": "chat"
}
```

Format di atas adalah skema internal aplikasi, bukan payload asli `youtubei.js`.

### Format data chat internal

```json
{
  "id": "tiktok-message-id",
  "platform": "tiktok",
  "username": "PlayerTwo",
  "displayName": "Player Two",
  "avatar": "https://example.com/avatar.jpg",
```

## 6. Unified Chat System

Gabungkan chat YouTube dan TikTok menggunakan satu format data internal.

### Requirement

- Semua chat ditampilkan dalam satu daftar.
- Setiap chat memiliki identitas platform.
- Chat YouTube menggunakan badge `YT`.
- Chat TikTok menggunakan badge `TT`.
- Setiap platform memiliki warna identitas berbeda.
- Chat diurutkan berdasarkan waktu penerimaan.
- Pesan baru muncul secara real-time.
- Chat tidak membutuhkan refresh manual.
- Avatar dapat ditampilkan atau disembunyikan.
- Pesan panjang harus membungkus baris dengan benar.
- Sistem memiliki batas jumlah pesan dalam memori.
- Pengguna dapat memfilter chat berdasarkan platform.

### Contoh tampilan

```text
[YOUTUBE] PlayerOne
Halo semuanya!

[TIKTOK] PlayerTwo
Gas terus bang!

[YOUTUBE] Viewer123
Semangat stream-nya!
```

### Persyaratan teknis

Buat tipe data bersama untuk seluruh event chat agar kedua adapter menggunakan struktur yang konsisten.

Contoh:

```typescript
type Platform = "youtube" | "tiktok";

interface ChatMessage {
  id: string;
  platform: Platform;
  username: string;
  displayName?: string;
  avatar?: string;
  message: string;
  timestamp: number;
  type: "chat";
}
```

## 7. OBS Browser Source Integration

Aplikasi harus menyediakan server lokal untuk menampilkan overlay pada OBS Studio.

### Endpoint overlay

Rancang endpoint berikut:

- `http://127.0.0.1:3210/overlay/chat`
- `http://127.0.0.1:3210/overlay/gifts`
- `http://127.0.0.1:3210/overlay/all`

Endpoint tersebut harus dibuat sebagai bagian dari implementasi aplikasi.

### Chat Overlay

Requirement:

- Background transparan sepenuhnya.
- Tidak menampilkan scrollbar.
- Mendukung OBS Browser Source.
- Ukuran overlay dapat disesuaikan.
- Chat baru muncul secara real-time.
- Overlay tetap berjalan ketika dashboard diminimalkan.
- Overlay dapat tersambung kembali setelah koneksi terputus.
- Chat YouTube dan TikTok memiliki badge berbeda.
- Pengguna dapat mengatur jumlah pesan yang tampil.
- Pengguna dapat mengatur durasi pesan.
- Pengguna dapat mengatur ukuran font.
- Pengguna dapat mengatur warna teks dan background.
- Pengguna dapat mengatur opacity.
- Pengguna dapat mengatur jarak antar-pesan.
- Pengguna dapat memilih animasi masuk dan keluar.
- Pengguna dapat menampilkan atau menyembunyikan avatar.

### Contoh tampilan

```text
┌────────────────────────────────────┐
│ [YT] PlayerOne                     │
│      Halo semuanya!                │
│                                    │
│ [TT] PlayerTwo                     │
│      Gas terus bang!               │
└────────────────────────────────────┘
```

### Requirement teknis

- Gunakan HTML, CSS, dan React untuk merender overlay.
- Gunakan WebSocket untuk mengirim event ke overlay.
- Server berjalan pada localhost secara default.
- Overlay tidak bergantung pada dashboard yang sedang terlihat.
- Koneksi WebSocket harus dapat dipulihkan.
- Event tidak boleh terduplikasi ketika overlay reconnect.
- Kegagalan overlay tidak boleh menghentikan pembacaan chat.

## 8. TikTok Gift Event System

Buat sistem khusus untuk menangani gift TikTok LIVE.

### Fitur

- Membaca event gift dari `tiktok-live-connector`.
- Mengambil username pengirim.
- Mengambil display name jika tersedia.
- Mengambil gift ID jika tersedia.
- Mengambil nama gift jika tersedia.
- Mengambil jumlah gift.
- Mengambil timestamp jika tersedia.
- Membedakan gift baru dan update gift streak.
- Mengirim event valid ke Gift Queue.
- Menampilkan event pada dashboard.
- Menampilkan animasi pada OBS.
- Menyediakan riwayat gift selama aplikasi berjalan.

### Format data gift internal

```json
{
  "id": "gift-event-001",
  "platform": "tiktok",
  "type": "gift",
  "username": "PlayerTwo",
  "displayName": "Player Two",
  "giftId": "5655",
  "giftName": "Rose",
  "giftCount": 5,
  "timestamp": 1793000000000
}
```

Format tersebut adalah skema internal aplikasi, bukan payload asli library.

### Penanganan gift streak

- Periksa indikator streak yang tersedia dari library.
- Jangan menghitung setiap update streak sebagai gift baru.
- Perbarui jumlah gift ketika streak bertambah.
- Proses gift final sesuai informasi event yang tersedia.
- Cegah duplikasi event.
- Jika metadata gift tidak lengkap, gunakan fallback.
- Pastikan jumlah gift yang ditampilkan tidak terhitung ganda.

## 9. Gift Animation System

Buat sistem animasi gift yang berjalan pada OBS Browser Source.

### Alur animasi

1. Event gift diterima.
2. Sistem memvalidasi dan menormalisasi event.
3. Event masuk ke antrean gift.
4. Overlay menerima event melalui WebSocket.
5. Animasi gift muncul.
6. Nama pengirim dan jumlah gift ditampilkan.
7. Animasi selesai.
8. Sistem memproses gift berikutnya.

### Contoh tampilan

```text
       ✨ GIFT ALERT ✨

          Player Two

          ROSE × 5
```

### Jenis animasi

- Slide In
- Fade In
- Pop Up
- Bounce
- Slide Out
- Fade Out

Gunakan CSS Keyframes untuk animasi dasar agar ringan dan mudah dikustomisasi.

### Pengaturan animasi

- Enable/Disable Gift Animation
- Animation Duration
- Animation Preset
- Gift Image
- Display Username
- Display Gift Name
- Display Gift Count
- Sound Effect
- Queue Limit
- Test Gift

### Persyaratan tambahan

- Animasi berjalan di OBS tanpa memerlukan dashboard terbuka.
- Animasi memiliki background transparan.
- Gift baru tidak langsung menimpa animasi yang sedang berjalan.
- Event diproses melalui antrean FIFO.
- Antrean memiliki batas maksimum.
- Gift dari pengirim yang sama dapat diperbarui ketika merupakan bagian dari streak.
- Sediakan gambar atau animasi fallback jika gambar gift tidak tersedia.
- Pengguna dapat menjalankan test animation tanpa live stream.

## 10. Event Queue System

Buat sistem antrean untuk menangani chat dan gift secara terpisah.

### Chat Queue

- Memproses event chat secara asynchronous.
- Menjaga urutan penerimaan event.
- Membatasi jumlah chat yang disimpan.
- Menghindari duplikasi pesan.
- Tidak menghambat penerimaan event baru.

### Gift Queue

- Menggunakan FIFO.
- Menjalankan satu animasi aktif pada satu waktu untuk MVP.
- Memiliki batas maksimum antrean.
- Menghindari duplikasi event.
- Mendukung update gift streak.
- Menghapus event yang telah selesai diproses.
- Menangani event yang tidak valid.
- Tetap menerima event meskipun overlay sedang reconnect.

## 15. Error Handling dan Reconnect

### YouTube

- Stream tidak ditemukan.
- Live chat tidak tersedia.
- Koneksi gagal.
- Koneksi terputus.
- Library mengalami error.
- Format event tidak sesuai.

### TikTok

- Live tidak ditemukan.
- Kreator tidak sedang live.
- Koneksi gagal.
- Koneksi terputus.
- Event gift tidak lengkap.
- Metadata gift tidak tersedia.
- Library mengalami error.

### OBS Overlay

- Server lokal tidak berjalan.
- WebSocket terputus.
- Browser Source di-refresh.
- Overlay gagal memuat aset.
- Event diterima berulang.

### Requirement

- Tampilkan error yang mudah dipahami.
- Gunakan reconnect dengan exponential backoff.
- Jangan melakukan reconnect tanpa jeda.
- Platform yang masih terhubung harus tetap berfungsi.
- Bersihkan listener saat koneksi ditutup.
- Hindari event listener ganda setelah reconnect.
